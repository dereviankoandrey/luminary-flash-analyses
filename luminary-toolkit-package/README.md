## Why This Toolkit?

**The Problem:** Most real estate investing tools are either:
- **Fuzzy scoring systems** that hide their logic (AI black boxes)
- **Overpriced subscriptions** ($50-200/mo) for basic calculators
- **Complex platforms** requiring training and onboarding

**Our Solution:** Deterministic, open-source, auditable tools that:
- Show you exactly how every number is calculated
- Cost $0 (open source forever free)
- Work offline in any browser — no account needed
- Can be verified by anyone with a calculator

**The Core Thesis:** If you can't verify the math yourself, don't trust it.
